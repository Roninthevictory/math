🔧 Firebase Setup Required

This engine uses Firebase Realtime Database to sync state across all viewers in real time. Setup is free and takes ~5 minutes.

  1. Go to console.firebase.google.com
  2. Create a new project (any name)
  3. Add a Web App → copy the firebaseConfig object
  4. Go to Realtime Database → Create database → Start in test mode
  5. Open this HTML file in a text editor
  6. Replace the firebaseConfig near the top with your values
  7. Save and re-upload to GitHub Pages / Google Sites

To open the master (engine runner) tab, add ?master to the URL. All other visitors are viewers and see the same live state.
